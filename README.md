# UrbanBite Cafe — Business Analytics

An Excel-based business analytics project designed to analyze cafe sales, profitability, customer behavior, product performance, and marketing effectiveness.

> **Note:** This project uses a simulated cafe dataset created for portfolio and business-analysis practice.

## 📊 Project Overview

The objective of this project is to convert raw cafe transaction and marketing data into actionable business insights using Microsoft Excel.

The analysis covers:

- Sales & Revenue Performance
- Gross Profitability
- Product Performance
- Customer Behavior
- Order Channel Performance
- Payment Method Performance
- Marketing Channel Performance
- Customer Acquisition Cost (CAC)
- Discount & Revenue Analysis

## 🛠️ Tools & Techniques

## 💡 Key Business Insights

- Dine-in generates the highest revenue among the order channels.
- UPI is the strongest payment method by revenue.
- Main Course contributes the highest gross profit among product categories.
- Masala Tea is the highest-selling product by quantity.
- Customer acquisition cost varies significantly across marketing channels.
- Returning customers contribute substantially to overall revenue.
